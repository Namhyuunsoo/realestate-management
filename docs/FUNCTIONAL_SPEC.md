# 부동산 관리 시스템 기능 명세서 (Functional Specification)

## 문서 정보
- **버전**: 1.0
- **작성일**: 2026-04-06
- **시스템명**: 부동산 매물 관리 시스템 (Real Estate Management System)

---

## 1. 시스템 개요

### 1.1 목적
부동산 중개사무소의 업무 효율화를 위한 종합 관리 시스템으로, 매물 관리, 고객 관리, 브리핑 생성, Google Sheets 연동 등의 기능을 제공한다.

### 1.2 사용자 역할
| 역할 | 설명 | 권한 범위 |
|------|------|----------|
| **Admin (관리자)** | 시스템 최고 관리자 | 모든 기능 접근, 사용자 관리, 시스템 설정 |
| **Manager (매니저)** | 중간 관리자 | 모든 매물/고객 조회, 주택 매물 관리 |
| **User (일반사용자)** | 중개사 직원 | 본인 담당 매물/고객만 조회 및 관리 |

## 2. 인증 및 사용자 관리

### 2.1 사용자 등록 (회원가입)

| 항목 | 내용 |
|------|------|
| **입력** | 이메일, 비밀번호(6자 이상), 이름(2자 이상) |
| **처리** | ① 이메일 형식 검증 ② 이메일 중복 확인 ③ 비밀번호 암호화 저장 ④ 계정 상태를 '승인 대기(pending)'로 설정 |
| **출력** | 등록된 사용자 정보 (ID, 이메일, 이름, 상태) |
| **예외** | 중복 이메일: "이미 등록된 이메일입니다" / 형식 오류: "올바른 이메일 형식이 아닙니다" |

### 2.2 로그인

| 항목 | 내용 |
|------|------|
| **입력** | 이메일, 비밀번호 |
| **처리** | ① 사용자 조회 ② 계정 상태 확인(pending/rejected/inactive/locked 시 차단) ③ 비밀번호 검증 ④ 로그인 실패 횟수 관리(5회 실패 시 30분 잠금) ⑤ 세션 생성 |
| **출력** | 로그인 성공 메시지, 사용자 정보(ID, 이메일, 이름, 역할, 상태, 할당 슬롯) |
| **예외** | 잘못된 인증정보: "이메일 또는 비밀번호가 올바르지 않습니다" / 승인대기: "관리자 승인 대기 중입니다" / 계정잠금: "계정이 잠겨있습니다. 잠시 후 다시 시도해주세요" |

### 2.3 로그아웃

| 항목 | 내용 |
|------|------|
| **입력** | 세션 정보 |
| **처리** | 세션 삭제 및 보안 이벤트 로깅 |
| **출력** | 로그아웃 완료 메시지 |

### 2.4 세션 확인

| 항목 | 내용 |
|------|------|
| **입력** | 세션 ID |
| **처리** | 세션 유효성 검증 및 사용자 활성 상태 확인 |
| **출력** | 로그인 여부, 사용자 정보 |

### 2.5 비밀번호 변경

| 항목 | 내용 |
|------|------|
| **입력** | 현재 비밀번호, 새 비밀번호 |
| **처리** | 현재 비밀번호 검증 후 새 비밀번호로 변경(암호화 저장) |
| **출력** | 변경 완료 메시지 |
| **예외** | 현재 비밀번호 불일치: "현재 비밀번호가 올바르지 않습니다" |

### 2.6 비밀번호 재설정 (관리자용)

| 항목 | 내용 |
|------|------|
| **입력** | 대상 사용자 ID, 새 비밀번호 |
| **처리** | 관리자 권한 확인 후 대상 사용자 비밀번호 변경 |
| **출력** | 재설정 완료 메시지 |
| **예외** | 권한 없음: "관리자 권한이 필요합니다" |

### 2.7 임시 비밀번호 발급

| 항목 | 내용 |
|------|------|
| **입력** | 이메일 |
| **처리** | 사용자 조회 후 8자리 랜덤 임시 비밀번호 생성 및 설정 |
| **출력** | 임시 비밀번호 |
| **예외** | 미등록 이메일: "등록되지 않은 이메일입니다" |

### 4.4 고객 정보 수정

| **예외** | 고객 없음: "고객을 찾을 수 없습니다" |

### 4.5 고객 삭제

| 항목 | 내용 |
|------|------|

## 5. 매물 관리

### 5.1 상가 매물 목록 조회

| 항목 | 내용 |
|------|------|
| **입력** | 현황 필터(생/계약/철거 등), 하위 카테고리(lease/unit/land), BBox 좌표(선택), 페이징(offset, limit), 압축 여부 |
| **처리** | ① Supabase 또는 로컬 캐시에서 매물 데이터 로드 ② 현황 필터 적용 ('생' 필터 시 빈 값도 활성 매물로 포함) ③ BBox 필터 적용(선택) ④ 페이징 적용 |
| **출력** | 매물 목록, 총 건수, 페이징 정보 |
| **참고** | 모든 사용자가 전체 매물 조회 가능 (담당자 구분 없이 표시) |

### 5.2 주택 매물 목록 조회

| 항목 | 내용 |
|------|------|
| **입력** | 하위 카테고리(sale/rent), 현황 필터, 페이징 |
| **처리** | 주택 매물 데이터 조회 |
| **출력** | 주택 매물 목록, 총 건수 |
| **권한** | 매니저, 관리자만 접근 가능 |

### 5.3 매물 현황 수정

| 항목 | 내용 |
|------|------|
| **입력** | 매물 ID, 새 현황 값 |
| **처리** | ① 매물 조회 ② 권한 확인 (관리자: 전체 가능, 일반사용자: 본인 담당 슬롯만, 주택: 매니저/관리자만) ③ Google Sheets 현황 컬럼 업데이트 |
| **출력** | 수정 결과 |
| **예외** | 권한 없음: "회원님의 담당 매물이 아니므로 현황을 수정할 수 없습니다" |

### 5.4 매물 캐시 삭제 (관리자용)

| 항목 | 내용 |
|------|------|
| **입력** | 관리자 인증 |
| **처리** | 로컬 매물 캐시 파일 삭제 |
| **출력** | 삭제 결과 |

### 5.5 매물 사진 조회

| 항목 | 내용 |
|------|------|
| **입력** | 매물 ID |
| **처리** | 해당 매물에 등록된 사진 목록 조회 |
| **출력** | 사진 목록 (URL, 업로드 일시, 업로더 등) |

### 5.6 매물 사진 업로드

| 항목 | 내용 |
|------|------|
| **입력** | 매물 ID, 이미지 파일 |
| **처리** | ① 파일 검증 ② Supabase Storage에 저장 ③ 메타데이터 기록 |
| **출력** | 업로드된 사진 정보 |
| **예외** | 파일 없음: "파일이 없습니다" |

### 5.7 매물 사진 삭제

| 항목 | 내용 |
|------|------|
| **입력** | 사진 ID |
| **처리** | ① 사진 조회 ② Storage에서 삭제 ③ 메타데이터 삭제 |
| **출력** | 삭제 결과 |

### 5.8 매물 등록

| 항목 | 내용 |
|------|------|
| **입력** | 매물 유형(상가임대차/구분상가매매/건물토지매매/주택 매매/주택임대차), 매물 정보 일체 |

| **출력** | 등록 성공 여부, 매물 ID |
| **예외** | 슬롯 없음: "담당자님께 할당된 매물장 시트를 찾을 수 없습니다" |

## 13. 외부 연동

### 13.1 Google Sheets
- **용도**: 매물 데이터 원본 저장소
- **동기화 방식**: 웹훅(실시간) + Cron(정기)
- **시트 유형**: 상가임대차, 구분상가매매, 건물토지매매, 주택 매매, 주택임대차

### 13.2 Supabase
- **용도**: 메인 데이터베이스, 파일 스토리지
- **테이블**: users, customers, briefings, 상가 매물(3종), 주택 매물(2종), sheet_registry, recommendations, geocode_cache

### 13.3 네이버 지도 API
- **용도**: 지오코딩 (주소 → 좌표 변환)
- **활용**: 매물 지도 표시, 거리 계산
